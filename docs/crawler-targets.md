# 크롤링 대상 검토 기록

## 공통 원칙

- 공개적으로 열람 가능한 정보만 수집합니다.
- `robots.txt`를 강제 준수하며 로그인, CAPTCHA, 유료 콘텐츠 또는 기술적 접근통제를
  우회하지 않습니다.
- 대상·필드·주기를 최소화하고 연락처가 포함된 식별 가능한 User-Agent를 사용합니다.
- 이용약관이 허용 범위를 명확히 주지 않으면 계약상 허가로 간주하지 않습니다.
- robots 허용은 저작권·데이터베이스권·개인정보 처리의 적법성을 보장하지 않습니다.

## 메가스터디

- 검토일: 2026-08-03
- 대상: `https://www.megastudy.net/teacher_v2/curriculum/main.asp`
- 수집 범위: 공개 강좌명, 과정 구분, 상태, 강좌 식별자, 과목 추정값
- 제외 범위: 회원정보, 후기, 수강신청·결제, 교재 본문, 강의·미리보기 영상, 로그인 뒤 정보
- 실측 선택자: `a.lecName[onclick*='fncChrDetailView']`
- 강좌 ID: `onclick`의 `fncChrDetailView('<course_id>', '<type>')`
- 과정 구분: 강좌 링크가 포함된 `tr`의 첫 번째 `th` 또는 `td`
- 이용약관: 공개 서비스의 이용관계를 규정하지만 자동수집 허가로 볼 명시 문구는 확인하지
  못했습니다. 따라서 robots 확인과 공개 목록 최소수집 외에는 별도 서면 허가가 필요합니다.
- robots 처리: 스파이더가 실행 시 직접 먼저 요청합니다. HTTP 200이 아니거나 해당 URL을
  허용하지 않으면 fail-closed로 중단합니다.
- 요청 정책: 1개 동시 요청, 최소 5초 지연, 자동 403/503 우회 및 브라우저 폴백 비활성화

페이지 구조 또는 정책이 바뀌면 수집을 자동 중단하고 이 기록과 선택자를 다시 검토해야 합니다.

- URL: `https://cafe.naver.com/eroulssam/583`
- 판단: 자동수집 대상에 추가하지 않음
- 사유:
  - 게시글 원문이 비로그인 공개 페이지에서 확인되지 않았고 카페 가입·회원 권한이 관련된
    콘텐츠일 가능성이 있습니다.
  - 네이버 이용약관은 사전 허락 없이 봇·스파이더·스크래퍼 등 자동화 수단으로 회원의
    게시물 등을 수집하는 행위를 금지합니다.
  - 로그인 쿠키 사용, CAPTCHA 또는 접근통제 우회는 robots 허용 여부와 무관하게 하지 않습니다.
- 허용 가능한 대안:
  - 게시물 작성자와 네이버 양측의 명시적인 서면 허가 및 제공 방식 확인
  - 권리자가 직접 제공한 원문 파일을 목적·보유기간·재배포 범위에 맞춰 수동 등록
  - 동일 정보의 공공데이터·공식 기관 원문을 별도로 확보

## 대학알리미 — 공식 OpenAPI 사용

- 검토일: 2026-08-03
- 제공기관: 한국대학교육협의회 대학정보공시센터
- API: `https://apis.data.go.kr/B340014/BasicInformationService_2/getUniversityCode`
- 인증: 공공데이터포털 활용신청 후 `DATA_GO_KR_SERVICE_KEY` 설정
- 수집 범위: 대학명·코드·학교/설립유형·지역·주소 등 API가 제공하는 대학 기본정보
- 이용조건: 무료, 개발·운영 자동승인, 이용허락범위 제한 없음
- 제한: 웹 화면을 크롤링하지 않고 공식 XML API만 사용하며 개발계정 일 1,000회 한도를 준수
- 구현: `crawler/edu_crawler/spiders/academyinfo_spider.py`

## 커리어넷 — 공식 Open API 사용

- 검토일: 2026-08-03
- 제공기관: 교육부·한국직업능력연구원

- 운영 원칙: 웹 화면을 스크래핑하지 않고 발급된 인증키로 공식 API만 호출하며 페이지당 100건씩 순차 요청
- 구현: `crawler/edu_crawler/spiders/careernet_spider.py`

- 검토일: 2026-08-03
- 구현: `api/app/university_admissions.py`, `GET /university-admissions`
- 1차 등재: 서울대, 연세대(서울), 고려대(서울), 성균관대, 한양대(서울), KAIST, POSTECH, 이화여대, 중앙대

- 안전장치: 중복 ID, HTTP 주소, 대학 외부 도메인을 애플리케이션 시작 전에 거부
- 운영 원칙: 모집요강을 복제하지 않고 공식 링크만 제공하며, 지원 전 반드시 해당 입학처에서 최신 모집요강과 변경 공지를 확인

- 범위: 서울·부산·대구·인천·광주·대전·울산·세종·경기·강원·충북·충남·전북·전남·경북·경남·제주 17개 시도

- robots 확인: 교육부 `robots.txt`에 일반 이용자를 차단하는 규칙이 확인되지 않았으며 Scrapy의 `ROBOTSTXT_OBEY=True`도 계속 적용

- 보류: 부산교육청은 게시물별 재이용 허가를 자동 판별할 일관된 표지가 확인되지 않아 미등재
- 보류: 경기도교육청은 게시물별 공공저작물 상업 이용 조건이 달라 자동 일괄 수집 대상에서 제외
