방법 03 · RTI / PBIS 통합 시스템

RTI · PBIS 통합 중재 시스템 실제 백엔드 연동

학업(RTI)과 행동(PBIS)을 하나의 통합 저장소에서 관리합니다. 학생 등록 → 스크리닝(위험도 식별) → 중재 배정 → 진도 모니터링 → 통합 프로필로 이어지는 증거기반 흐름을 직접 실행해 보세요.

① 학생 등록 (Student Core)

② 보편적 스크리닝 + 위험도 식별

진단 모델 · 계량 기준 · 데이터 근거 보기

진단 데이터 소스(3개, 교사 개입 없음): ① 학생 자가보고 ② 학부모 보고 ③ 교육기관 공개 자료(성적표·출결·학교생활기록·진로·비교과 공개 항목). 교사 평정은 사기업 모델에서 비활성.

도출 지표정의위험(계량) 기준입력 소스 (학생 / 학부모 / 교육기관)
math_percentile_rank
수학 백분위		수학 학업 성취의 또래 대비 상대 위치(0–100).< 25 → 학업 위험학생: 수학 자신감·숙제 빈도·개념 이해 문항 / 학부모: 성적 추이·과외 여부 / 기관: 성적표 수학 석차백분위·수행평가
reading_benchmark_score
읽기 벤치마크		읽기(국어/영어) 성취 벤치마크(0–100). 수학과 동일 계량선.< 25 → 학업 위험학생: 독해·요약·어휘 문항 / 학부모: 독서량·과목 어려움 / 기관: 국어·영어 성적·독서 기록
behavioral_risk_index
행동 위험지수		규칙준수·충동·과제지속·휴대전화 등 종합 지수(0–100, 높을수록 위험).> 70 → 행동 위험학생: 준법·집중·스크린 사용 문항 / 학부모: 규칙·생활패턴·수면 / 기관: 출결·지각·봉사·비교과
social_skills_rating
사회성 기술		또래관계·협동·자기조절 등 사회성(0–100, 높을수록 양호).< 40 → 보완 필요학생: 교우·협력·갈등조절 문항 / 학부모: 대인관계·활동 참여 / 기관: 동아리·행사·창의체험

계량 기준은 RTI/MTSS 보편적 스크리닝 관행(학업 하위 25% 위험선, 행동 고위험 컷)을 참고한 참고값. 각 지표는 3소스 응답을 가중 융합(학생 40%·학부모 30%·교육기관 30%)해 산출. Tier = 위험 영역 수에 따라 1(안전)·2(단일)·3(학업+행동 동시).

진단 입력: 교사 평가 없이 학생·학부모·교육기관 3개 소스만으로 진단합니다. 각 소스의 질문지에 객관적 기준으로 응답하세요. 3소스가 모두 입력되면 더 정밀한 융합 진단이 가능합니다(미입력 소스는 융합 가중에서 제외).

학생 본인이 평가합니다. 각 문항의 객관적 기준 중 본인 상황과 가장 가까운 것을 선택하세요(1~5 → 0~100 환산).

학부모가 자녀를 관찰해 평가합니다. 각 문항의 객관적 기준 중 가장 가까운 것을 선택하세요(1~5 → 0~100 환산).

학교·학원 등 교육기관이 공개한 자료(성적표·출결·학교생활기록·진로·비교과)에서 확인 가능한 항목입니다. 각 기준 중 가장 가까운 것을 선택하세요(1~5 → 0~100 환산).

미입력 소스는 융합에서 제외(가중 재분배). 직접 입력 모드 선택 시 그 값을 그대로 사용.
