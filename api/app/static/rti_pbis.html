방법 03 · RTI / PBIS 통합 시스템

RTI · PBIS 통합 중재 시스템 실제 백엔드 연동

학업(RTI)과 행동(PBIS)을 하나의 통합 저장소에서 관리합니다. 학생 등록 → 스크리닝(위험도 식별) → 중재 배정 → 진도 모니터링 → 통합 프로필로 이어지는 증거기반 흐름을 직접 실행해 보세요.

① 학생 등록 (Student Core)

② 보편적 스크리닝 + 위험도 식별

③ 중재 배정 (Intervention)

④ 진도 모니터링 (Progress Monitoring)

⑤ FBA 지원 (A-B-C → 가설)

⑥ 통합 학생 프로필

아키텍처
· 데이터 수집 계층: POST /rti/student·screening·intervention·pm-*·fidelity
· 통합 저장소: rti_student / rti_screening / rti_pm_* / rti_intervention / rti_fidelity (SQLAlchemy ORM — SQLite·PostgreSQL 호환)
· 분석 엔진: identify_risk / evaluate_progress / analyze_fba (app/rti_pbis_engine.py)
· 확장 지점: 시계열 진도 데이터는 관계형 timestamp로 두고, 운영 시 InfluxDB로 분리 가능
모델: RTI(Response to Intervention) · PBIS(Positive Behavioral Interventions and Supports). 본 시스템은 MTSS 관점에서 학업·행동 데이터를 통합해 증거기반 의사결정을 지원합니다.
