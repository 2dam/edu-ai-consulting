방법 03 · RTI / PBIS 통합 시스템

RTI · PBIS 통합 중재 시스템 실제 백엔드 연동

학업(RTI)과 행동(PBIS)을 하나의 통합 저장소에서 관리합니다. 학생 등록 → 스크리닝(위험도 식별) → 중재 배정 → 진도 모니터링 → 통합 프로필로 이어지는 증거기반 흐름을 직접 실행해 보세요.

① 학생 등록 (Student Core)

② 보편적 스크리닝 + 위험도 식별

용어 · 계량 기준 · 데이터 근거 보기
지표정의단위 / 범위위험(계량) 기준데이터 근거 (입력 출처)
math_percentile_rank
수학 백분위		표준화 학업성취도에서의 수학 백분위. 또래 대비 상대 위치.백분위 0–100< 25 → 학업 위험 (하위 25%)국가/교육청 학업성취도 평가, 표준화 진단(예: K-CT, CBM)의 백분위
reading_benchmark_score
읽기 벤치마크		읽기(국어/영어) 성취 벤치마크 점수. 수학과 동일 계량선 적용.점수 0–100< 25 → 학업 위험 (벤치마크 미도달)읽기 진단(예: DIBELS/K-CT 읽기), 표준화 읽기 평가 점수
behavioral_risk_index
행동 위험지수		문제행동 빈도·강도·지속을 종합한 지수. 높을수록 위험.지수 0–100> 70 → 행동 위험교사 평정(SSBD), CICO 일일점수, 사건 로그 빈도 환산
social_skills_rating
사회성 기술		또래관계·협동·자기조절 등 사회성 기술 평정.평정 0–100< 40 → 보완 필요사회성 평정(예: SSIS, BASC-3) 표준점수 환산

계량 기준은 미국 RTI/MTSS 보편적 스크리닝 관행(학업 하위 25% 위험선, 행동 고위험 컷)을 참고해 설정한 참고값입니다. 실제 적용 시 학교·지역 표준화 데이터로 재보정 권장. Tier = 학업 또는 행동 위험 영역 수에 따라 1(안전)·2(단일 영역)·3(학업+행동 동시).

사회성(SSIS/BASC형)·행동 위험(SSBD형) 자기/교사 평정 문항입니다. 각 문항의 객관적 기준 중 본인 상황과 가장 가까운 것을 선택하세요(1~5 → 0~100 환산).

미응답 문항은 현재 값(직접 입력)으로 유지됩니다.

표준화 검사 결과를 붙여넣으면 4지표로 환산합니다. 모르는 항목은 비워두세요.

미입력 항목은 현재 값(직접 입력)으로 유지됩니다.
