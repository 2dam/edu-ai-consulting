방법 01 · TimesFM 참조

시계열 성적·행동 예측 실제 모델 연동

학생의 월별 성적(또는 출결·학습행동 정규점수 0~100)을 입력하면, 시계열 추세를 분석해 향후 추이를 예측합니다. TimesFM 계열 시계열 기초모델을 참조한 경량 예측(선형추세 + 이동평균 잔차보정)이 백엔드에서 실제로 계산됩니다.

—
참조: google-research/timesfm (Foundation Model for Time Series). 본 데모는 거대 FM 대신 경량 시계열 회귀로 구현했으며, 실서비스에서는 TimesFM 추론을 백엔드 엔드포인트(/timesfm-predict)에 교체 연결합니다.
