방법 02 · Understand-Anything 참조

학생·학부모·교사 상호이해 모델 실제 백엔드 연동

세 주체 각각의 발화(의도·상황)를 입력하면, 다중 에이전트 파이프라인(프로필 수집 → 지식그래프 구축 → 상호이해 분석 → 리포트 생성 → 실행계획)이 오해 지점을 정리하고 실질적인 도움 액션을 제안합니다. 백엔드 /api/understand/analyze에서 실제로 분석됩니다.

② 상호이해 점수 / 갭 / 리포트

위 ① 분석 실행 후 세션이 생성됩니다. 세션 ID로 점수·갭·페르소나별 리포트를 조회합니다.

참조: Egonex-AI/Understand-Anything (다자 간 이해 모델). 본 구현은 명세의 지식그래프 + 6개 에이전트 파이프라인을 실제 SQLAlchemy 모델·백엔드로 옮겼으며, LLM 미설치 시 통계·휴리스틱 폴백(statistical-fallback)으로 동작합니다. 표시 수치는 데모용 샘플(빈 입력 기준 산출값)이며 실제 입력 적재 시 실제 분석으로 대체됩니다.
